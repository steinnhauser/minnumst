# Changelog

Releases of `deploy`, tagged `deploy-<version>`. Entries since the monorepo are generated by `make release` from Conventional Commits; versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.4.0 (2026-11-01)

### Feat

- keep import batches out of Git and off the host
- route suggestions and editor routes, add a separate import playbook
- run Authentik in the stack, configured by a blueprint
- encrypt the data volume and keep Docker's data on it
- provision the host on Hetzner Cloud with OpenTofu

### Fix

- let browsers' preflight reach editor routes
- make restores atomic and smoke-test the editor routes
- rate limit new SSH connections per source
- keep the controller's credentials out of the smoke test
- reach the stack over IPv6, and keep secrets out of deploy diffs
- keep the mail server on loopback and mount /tmp as a hardened tmpfs
- read facts through ansible_facts and stop injecting them as variables
- set the data volume's root permissions after mounting it

## 0.3.0 (2026-10-25)

### Feat

- smoke test the live site and document rotation and rollback
- file integrity monitoring and local account policy
- nightly encrypted backups with a tested restore
- migrate as the schema owner and run the API as a runtime role

### Fix

- record the AIDE baseline detached, and make it optional
- create the pwquality drop-in directory before writing to it

## 0.2.0 (2026-10-25)

- mount the PostgreSQL role script as a file
